# Phase 0A acceptance checklist

- [ ] `pio run -e cyd4` succeeds
- [ ] upload to COM4 succeeds
- [ ] serial output appears at 115200
- [ ] backlight is on
- [ ] full 480x320 landscape UI appears
- [ ] touch calibration completes
- [ ] touch marker follows the finger
- [ ] all screen corners are reachable
- [ ] calibration survives reboot
- [ ] no persistent display flicker
- [ ] no reboot loop / watchdog reset
