# Phase 0L.1 — Timing & Presentation Polish

Parent: Phase 0L visual-library integration PASS.

No approved art was redesigned.

## Action timing
Direct actions now use a five-stage presentation curve:
- anticipation
- build
- readable peak
- recovery
- settle

The 3-frame approved sequences are presented as:
`0 -> 1 -> 2 -> 1 -> 0`

Station interactions use a smoother repeating cadence:
`0 -> 1 -> 2 -> 1`

The peak frame receives more screen time so high-detail art is readable.

## Sleep
Sleep 01 / 04 now use a slower breathing cadence:
`0 -> 1 -> 2 -> 1`

This removes the abrupt `0 -> 1 -> 2 -> 0` loop.

## Reaction emotes
Friendly and annoyed reaction emotes now:
- remain visible for 1.25 s
- pop upward into position
- hold near Ghost
- drift slightly upward on exit
- use small holographic corner brackets
- use subtle animated sparkle accents

The approved emote art itself is unchanged.
