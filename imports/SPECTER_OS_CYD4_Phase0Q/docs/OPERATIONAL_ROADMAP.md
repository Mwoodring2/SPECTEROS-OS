# SPECTER//OS operational roadmap

Product priority is now operational capability first.

Ghost is the visual/personality shell around system state.

- asynchronous discovery
- RF summary state
- operational telemetry in primary UI

## Candidate follow-on phases
1. Network inventory / observed-device table
2. Passive channel intelligence and RF-density view
3. SD logging of passive observations
4. Detection signatures / alert framework
5. GPS-aware field logging
6. Capture subsystem for authorized testing environments
7. Plugin/tool registration architecture

The separate full Ghost virtual-pet fork is deferred until the operational SPECTER//OS build is complete.
